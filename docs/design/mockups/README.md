# Mockups

Rendered from the "Mosaic River Mockups" design canvas on 2026-10-20. They are a starting point for layout, not a pixel target; Adam expects the layout to change once the River is in use. The render used fallback fonts (the real ones are Newsreader and Nunito Sans for the Mosaic theme, Libre Franklin and Inter for Civic).

- `everything-desktop.png`: Everything mode, desktop. Filters in the left column (search, circles, content type), Live and Sample labels, the Sample explainer.
- `civic-desktop.png`: Civic mode (the Citizen Dashboard), with the Coming up panel and two placeholder slots.
- `phone.png`: the River at 390 px with the chip row and bottom tabs.
- `following.png`: the Following page with Spaces, Quiet and Ended.

Later design direction (Decisions Log, after the second mockups): all filtering stays in the left column; "Kinds" is not settled and Samples should not appear there; inline playback of podcasts and videos is wanted later.
