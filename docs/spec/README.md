# Spec

- `river-v1.md`: the Mosaic River v1 build spec (draft 3, approved by Adam on 2026-10-20). It has the seven parts this folder asks for (goal, users and flows, data model, sources and protocols, out of scope, acceptance checks, build order) plus appendices on architecture, security, ADRs, configuration and open items.
- Accepted design decisions: `decisions/001` to `006`.
- Background, read only when the spec points there: `docs/design/` (Decisions Log, Phase 2 architecture notes, mockups). Where background and spec differ, the spec wins.
- `ui-revisions-1.md`: UI revisions Adam decided on 2026-10-21 (reader view, filter pills and chips, networks, Civic circles, Coming up in Everything, grouped hub cards, the sample line). Where it differs from `river-v1.md`, it wins.
- `ui-revisions-2.md`: UI revisions Adam decided on 2026-10-21 (items open in an embedded view of the original source, or in a full-width reader when the source refuses framing; the filter column stays put). Where it differs from `ui-revisions-1.md` or `river-v1.md`, it wins.
- `ui-revisions-3.md`: UI revisions Adam decided on 2026-10-22 (fediverse posts stay in the feed with an "Open ↗" button; other items framed or opened in a new tab; a narrower River bar; the filter column scrolls on its own and gets "Clear all"). Where it differs from earlier revisions, it wins.
