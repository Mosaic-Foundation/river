# Spec

- `river-v1.md`: the Mosaic River v1 build spec (draft 3, approved by Adam on 2026-10-20). It has the seven parts this folder asks for (goal, users and flows, data model, sources and protocols, out of scope, acceptance checks, build order) plus appendices on architecture, security, ADRs, configuration and open items.
- Accepted design decisions: `decisions/001` to `006`.
- Background, read only when the spec points there: `docs/design/` (Decisions Log, Phase 2 architecture notes, mockups). Where background and spec differ, the spec wins.
- `ui-revisions-1.md`: UI revisions Adam decided on 2026-10-21 (reader view, filter pills and chips, networks, Civic circles, Coming up in Everything, grouped hub cards, the sample line). Where it differs from `river-v1.md`, it wins.
- `ui-revisions-2.md`: UI revisions Adam decided on 2026-10-21 (items open in an embedded view of the original source, or in a full-width reader when the source refuses framing; the filter column stays put). Where it differs from `ui-revisions-1.md` or `river-v1.md`, it wins.
- `ui-revisions-3.md`: UI revisions Adam decided on 2026-10-22 (fediverse posts stay in the feed with an "Open ↗" button; other items framed or opened in a new tab; a narrower River bar; the filter column scrolls on its own and gets "Clear all"). Where it differs from earlier revisions, it wins.
- `ui-revisions-4.md`: UI revisions Adam decided on 2026-10-23 (circles are multi-select; the Circles section shows six circles and scrolls; a "Filter your River" title; a compact "Clear all"; no active-filter chips above the feed). Where it differs from earlier revisions, it wins.
- `ui-revisions-5.md`: UI revisions Adam decided on 2026-10-23 (the feed starts with an item: no visible title, unread count, sort line or "Mark all read"; Civic mode's top bar says "Citizen Dashboard"). Where it differs from earlier revisions, it wins.
- `ui-revisions-6.md`: the mobile filter Adam decided on 2026-10-23 (one "Filter your River" button with a count and summary, opening a bottom sheet with the column's filters as wrapping pills, live, closable every usual way, as an accessible modal dialog). Sent as "ui-revisions-5.md", which was taken. Where it differs from earlier revisions, it wins.
- `bluesky-1.md`: the first Bluesky step of Phase 2 (Adam, 2026-10-23): ADR-009, a Bluesky adapter (handles, bsky.app profile URLs and DIDs, keyed by DID), "Bluesky" in the Networks filter, and "Import from Bluesky". It brings in the atproto adapter that `river-v1.md` 4.1 left as a stub and section 5 left out of v1. Where it differs from earlier files, it wins.
- `ui-revisions-7.md`: a circles menu on each Following row (Adam, 2026-10-23): a "Circles" menu button showing the row's circles, a menu of every circle to check or uncheck (saved immediately, undone on failure), "New circle…" to create one with the row in it, keyboard and screen-reader support, and a small bottom sheet on phones. The Circles panel's editor stays. Where it differs from earlier files, it wins.
- `ui-revisions-8.md`: UI revisions Adam asked for on 2026-10-24: Coming up back in Everything (its plugin also reads dated items, and the column stays when empty); the filter column's circles as wrapping pills, four rows then scrolling; and the whole window on a desktop, with the filters against the left edge, Coming up against the right and the feed centred between (Facebook as the reference). Where it differs from earlier revisions, it wins.
